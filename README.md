## Ficheiros
- `index.html`: conteúdo e estrutura.
- `style.css`: layout, temas, animações e responsividade.
- `script.js`: menu móvel, alternância de tema, animações e feedback via WhatsApp.
- `assets/`: retrato e capturas dos projectos.

## Testar
Extrai o ZIP e abre `index.html` no navegador. As fontes e os ícones das tecnologias precisam de ligação à internet.

## Publicar
Podes publicar a pasta extraída no Netlify ou a partir de um repositório GitHub. Antes de partilhares o endereço público, testa os links dos projectos, o email, o GitHub e o WhatsApp.

O formulário de feedback não guarda dados num servidor: abre o WhatsApp com a mensagem preparada. A secção CCNA apresenta uma síntese de áreas introdutórias de redes e não pretende reproduzir literalmente uma versão específica do currículo oficial da Cisco.
